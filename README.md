# Maharajas' Express

A luxury travel website for the **Maharajas' Express**, India's luxury train, built with React and Vite. It is a redesign concept for a booking agent's site, with a brown, gold and crimson palette and a liquid-glass navigation bar.

## Features

- Home page with hero carousel, contact numbers, About section with a "Read more" panel, journey cards, booking guide, booking form, testimonials and FAQ
- Inner pages: journeys (with detail pages), the train and its cabins, destinations, fares, gallery, video gallery, offers, contact, feedback, about, other trains, privacy policy and terms
- Fully responsive, from phones to large desktops
- Client-side routing with React Router

## Tech stack

- React 18
- Vite
- React Router
- Plain CSS (no UI library)

## Notes

- Images other than the logo and hero images are internet placeholders and should be replaced.
- Testimonials, offers, departure dates and legal pages are sample content.
- The booking and feedback forms currently validate and show a confirmation but do not send data anywhere. Connect them to an email service or backend before going live.
